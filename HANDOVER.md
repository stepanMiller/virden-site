# VIRDEN: передача проекта владельцу

## Что является рабочим сайтом
- Публичный адрес: https://virden.ru/
- Хостинг опубликованной версии: Beget. Исходники в GitHub сами по себе не обновляют сайт на Beget.
- Исходный код: ветка `main` этого репозитория. Сборка Next.js экспортирует статические файлы в `out/`.
- Превью GitHub Pages разворачивается отдельно из `codex/first-production-pass`. Оно не является рабочим сайтом.

## Как вносить изменения
1. Изменить исходники в отдельной ветке и проверить `pnpm lint`, `pnpm build`, `pnpm check:export`.
2. Для рабочего домена собрать с `NEXT_PUBLIC_SITE_URL=https://virden.ru` и пустым `NEXT_PUBLIC_BASE_PATH`.
3. Проверить файлы `out/` и загрузить **содержимое** этой папки в каталог действующего сайта на Beget с резервной копией текущей версии.
4. Проверить HTTPS, главную и страницы категорий, изображения, ссылки MAX, `robots.txt`, `sitemap.xml`, мобильный экран и отсутствие ошибок.

## Важная незавершённая работа
- Яндекс Метрика № 113124000 и цель «Переход в MAX» были созданы, но изменения для сайта находятся в отдельном PR #1. Не считать их опубликованными на virden.ru, пока код не собран, не загружен на Beget и не проверен в Метрике.
- Права на домен, Beget, Метрику, Вебмастер и рекламный кабинет передаются отдельно от этого репозитория. Не передавать пароли через GitHub.
- Сверять фактический состав опубликованного `out/` с исходником перед очередным выпуском. Старые архивы сборки не использовать без проверки.
